### 3.2 API — Middleware

**`api/src/middleware/auth.ts`**
- Intention: `requireApiKey` (Bearer `ts_` format) validates API keys via `authService`; `optionalAuth` tries auth silently.
- Dependencies: `authService`, `extractClientIp`, `logger`.
- Flaw (read directly):
  - `optionalAuth` silently swallows errors (catch block ignores everything) — could hide revocation or DB failures.
  - `requireApiKey` logs `request.socket.remoteAddress` instead of `extractClientIp(request)` — proxy spoof vulnerability.
  - `rawKey.length < 20 || rawKey.length > 80` is basic length check; no cryptographic format validation beyond `ts_` prefix.
  - `request.authContext = ctx` assigns without TypeScript narrowing; `optionalAuth` does not enforce anything.

**`api/src/middleware/rate-limit.ts`**
- Intention: `proxyRateLimit` applies per-org or per-IP rate limits before proxying.
- Dependencies: `rateLimiter`, `env`.
- Flaw (read directly):
  - Key selection: `request.authContext?.orgId ?? request.socket.remoteAddress ?? 'unknown'` — falls back to spoofable IP when auth missing.
  - Uses `env.RATE_LIMIT_PROXY_ORG`; if env undefined or misconfigured, rate limit may fail silently.
  - Header response (`X-RateLimit-*`) is set but not enforced by `@fastify/rate-limit` plugin; custom `rate-limiter.ts` handles logic separately.

**`api/src/middleware/error-handler.ts`**
- Intention: Centralized error response formatting.
- Flaw: Not inspected in detail; likely basic error wrapper; may not distinguish between 401/403/500 properly; may leak internal stack traces if `NODE_ENV` misconfigured.
