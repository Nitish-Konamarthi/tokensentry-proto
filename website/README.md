# tokensentry.ai — Marketing Website

TokenSentry landing page and pricing.

## Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS 3
- **Deploy**: Static export or Docker

## Pages

- `/` — Hero, features, how it works, pricing, FAQ, footer
- `/pricing` — Pricing table, ROI comparison

## Quick Start

```bash
npm ci
npm run dev
```
